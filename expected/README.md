# 正解データ

ラベルは before 単体の正しさではなく、変更依頼に対する before → after の変更が終わった時点での状態を表します。

- A 必須漏れ: 新しい桁数に合わせる必要がある仕様や動作が古いままです。
- B 保守上の古さ: 動作を直接制限しませんが、コメントなどの説明が古いままです。
- C 変更不要・別項目: 桁数の変更を必要としない参照・表示、または依頼に含まれない別項目です。
- 変更済み: 依頼に沿って更新されています。E1 は変更の起点、E3 は更新済みの項目一覧です。

AIレビューには expected/ も repo の URL も渡さず、fixtures/ だけをコピーして渡してください。

## ファイルと地点

- `labels.csv`: E1–E8 と S1–S8 の計16地点。パスは repo 直下からの相対パスです。Excel の結合セルは左上セル、C# は1始まりの行番号を使います。C# の内容欄は字下げも含む行全体です。
- `allowlist.csv`: 評価地点以外の出現を版ごとに列挙します。Designer のフィールド宣言・初期化2行とフォームへのコントロール登録1行、各版3地点（合計6行）です。これらはフォームを構成する参照であり、桁数を指定しません。通常のフィールド名を不自然に変えて出現を隠すことはしていません。
- `cells-before.txt` / `cells-after.txt`: 全シートの使用範囲内の全セル値です。空セルと結合セルの左上以外も `null` として記録します。各行は `[ファイル名, シート名, セル番地, 値]` の JSON 配列です。ファイル名は版のフォルダからの相対パス、日付は ISO 8601 形式です。

## 生成・確認

Python 3 と openpyxl を使います。初回確認環境は Python 3.12.14 / openpyxl 3.1.5 です。

```sh
python scripts/generate_fixtures.py
python scripts/dump_cells.py
python scripts/validate_fixtures.py
```

再現性は、再生成前後で保存した2本のセル dump がそれぞれ一致することで確認します。XLSX のファイルハッシュは比較しません。生成スクリプトは fixtures/ のみを生成し、正解ラベルは自動的に上書きしません。

検証スクリプトは fixtures/docs と fixtures/src の before・after のみを走査します。Excel は openpyxl でセル値を読み、C# は行テキストを読みます。英字の検索語は大文字小文字を区別して部分一致、20 は前後に数字がない場合だけ一致とします。同じ地点に複数の検索語があっても1地点として扱い、すべてを labels.csv または allowlist.csv と照合します。地点の存在・内容、評価地点の数、E1/E3 だけのセル差分、ソースの同一性、版間の書式・印刷設定の同一性、保存済み dump との一致も確認します。変更漏れを推論する解析器ではありません。
